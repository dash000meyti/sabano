# صبانو — وب‌سایت صندوق پژوهش و فناوری غیردولتی صبانو

بازطراحی کامل sabano.ir با **Next.js 16**، **SQLite** و پنل مدیریت، در یک مونوریپو و یک کانتینر.

- ۵ زبان: فارسی (ریشه، RTL)، English، 简体中文، Русский، Español
- صفحات: خانه، درباره، مدیران، خدمات (+۵ صفحهٔ خدمت)، سرمایه‌گذاری، فرایند جذب سرمایه، پورتفولیو، اخبار و تحلیل، پرسش‌های متداول، فرصت‌های همکاری (فرم با پیوست)، تماس، حریم خصوصی، جست‌وجو
- سئو، جیو و ایو: متادیتا و hreflang، JSON-LD (FinancialService، Service، FAQPage، HowTo، Article، Person، BreadcrumbList)، `sitemap.xml`، `robots.txt`، `llms.txt` و `llms-full.txt`، RSS، تصاویر OG برای همهٔ صفحه‌ها و زبان‌ها، IndexNow، ریدایرکت ۳۰۸ همهٔ نشانی‌های قدیمی `.html`
- پنل مدیریت فارسی در `/admin`: درخواست‌ها، اخبار (ویرایشگر Tiptap)، FAQ، مدیران، پورتفولیو، نهادهای مرتبط، سهامداران، رسانه، تنظیمات، کاربران، پشتیبان‌گیری

## ساختار

```
apps/web          اپ Next.js (سایت + پنل + API)
packages/db       schema (Drizzle)، migrationها، seed، کوئری‌ها
packages/i18n     تنظیم زبان‌ها + messages/{fa,en,zh,ru,es}.json
packages/ui       توکن‌های طراحی (Tailwind v4) و کلاس‌های پایه
packages/config   tsconfig مشترک
scripts/          ساخت تصاویر OG و آماده‌سازی تصاویر
```

## اجرای محلی

پیش‌نیاز: Node 22 و pnpm 9

```bash
pnpm install
```

```bash
pnpm db:seed
```

```bash
pnpm admin:create
```

```bash
pnpm dev
```

سایت روی `http://localhost:3000` و پنل روی `http://localhost:3000/admin` بالا می‌آید. داده‌ها در پوشهٔ `data/` در ریشهٔ مخزن ذخیره می‌شوند.

## تست‌ها

| دستور | کار |
|---|---|
| `pnpm typecheck` | بررسی TypeScript |
| `pnpm lint` | ESLint |
| `pnpm test` | تست‌های واحد (Vitest) + بررسی کامل‌بودن ترجمه‌ها |
| `pnpm i18n:check` | همهٔ زبان‌ها کلیدها، آرایه‌ها و placeholderهای یکسان دارند |
| `pnpm e2e` | تست‌های Playwright روی سرور در حال اجرا (`BASE_URL`؛ برای تست پنل `E2E_ADMIN_EMAIL` و `E2E_ADMIN_PASSWORD`) |

## استقرار با داکر (یک کانتینر)

```bash
cp .env.example .env
```

مقادیر `.env` را پر کنید (حداقل `SESSION_SECRET` و برای اولین اجرا `ADMIN_EMAIL` و `ADMIN_PASSWORD`). سپس:

```bash
docker compose up -d --build
```

- کانتینر روی `127.0.0.1:3000` گوش می‌دهد؛ nginx فعلی را به‌عنوان reverse proxy (با TLS) جلوی آن بگذارید.
- همهٔ داده‌های ماندگار در volume `/data` هستند: `sabano.db`، `uploads/` (پیوست‌های فرم)، `media/` (تصاویر پنل) و `backups/`.
- در هر بار اجرا: migrationها اعمال می‌شوند، دیتابیس خالی با محتوای فعلی سایت seed می‌شود، اولین مدیر از env ساخته می‌شود و پشتیبان‌گیری روزانه (۱۴ نسخه) زمان‌بندی می‌شود.
- سلامت: `GET /api/health`

نمونهٔ تنظیم nginx:

```nginx
location / {
  proxy_pass http://127.0.0.1:3000;
  proxy_set_header Host $host;
  proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
  proxy_set_header X-Forwarded-Proto $scheme;
  client_max_body_size 10m;
}
```

## محتوا

- **متن ثابت صفحات** (خدمات، محورهای سرمایه‌گذاری، فرایند، حریم خصوصی و…) در `packages/i18n/messages/*.json` است.
- **محتوای پویا** (اخبار، FAQ، مدیران، پورتفولیو، نهادها، سهامداران، تماس، شبکه‌های اجتماعی، آمار) از پنل مدیریت ویرایش می‌شود. هر ذخیره، کش سایت را تازه می‌کند و در production به IndexNow اطلاع می‌دهد.
- **تصاویر OG** بعد از تغییر متن‌ها با `node scripts/generate-og.mjs` دوباره ساخته می‌شوند (نیاز به `pnpm exec playwright install chromium`).

## موارد نیازمند تأیید یا تکمیل توسط صندوق

1. **لوگو:** نسخهٔ SVG رسمی (روشن، تیره و آیکون). فعلاً PNG سایت قبلی استفاده شده است (`apps/web/public/images/brand/`).
2. **فونت:** فایل‌های IRANYekan روی سایت قبلی وجود نداشت (۴۰۴). سایت جدید از Vazirmatn (رایگان، OFL) استفاده می‌کند.
3. **اطلاعات حقوقی:** سال تأسیس، شمارهٔ ثبت و شناسهٔ ملی (پنل ← تنظیمات).
4. **ساعات کاری و مختصات نقشه:** خالی گذاشته شده‌اند (پنل ← تنظیمات).
5. **پورتفولیو:** داده‌ای وجود ندارد. تا وقتی شرکتی منتشر نشده، صفحه noindex است و از منو و sitemap حذف می‌شود.
6. **مدیران:** عکس علی سلیمی، و تأیید نام کامل مدیرعامل (روی سایت قبلی «مهدی صداقت ا.» آمده ولی نام فایل عکس hamed-sedaghat است).
7. **شبکه‌های اجتماعی:** فقط لینکدین فعال است. بله، تلگرام، آپارات و واتساپ روی سایت قبلی لینک نداشتند.
8. **محتوای نوشته‌شده:** جزئیات خدمات، مراحل فرایند، FAQها و سه مقالهٔ راهنما بر پایهٔ متن سایت قبلی و قواعد عمومی صندوق‌های پژوهش و فناوری نوشته شده‌اند و هیچ عدد، نرخ یا زمان‌بندی‌ای در آن‌ها نیست. لطفاً صحت آن‌ها را تأیید کنید.
9. **ترجمه‌ها:** ترجمه‌های چینی، روسی و اسپانیایی باید توسط یک گویشور بومی بازبینی شوند. در نسخه‌های خارجی سایت قبلی، مبلغ «۱۰۰۰ میلیارد تومان» اشتباه به حدود ۳.۷ میلیارد دلار تبدیل شده بود. این تبدیل حذف شده است.
10. **SMTP:** برای اعلان ایمیلی درخواست‌های جدید، متغیرهای `SMTP_*` و `NOTIFY_EMAIL` را تنظیم کنید.
